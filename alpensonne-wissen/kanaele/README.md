# Kanäle

**Zweck:** Eine Datei pro OTA/Partner. Laufende Kampagnen stehen nicht hier, sondern im Raten-Cockpit.
**Ist-Stand:** Kanaldateien folgen.
**Abhängigkeiten:** `stammdaten/raten/`, DIRS21, Raten-Cockpit

## Regel für Kampagnen
Keine Kampagne geht live (Booking.com, Expedia, Airbnb, Website …), ohne dass sie im Raten-Cockpit eingetragen ist:
Kanal, Buchungszeitraum, Aufenthaltszeitraum, Rabatt, kombinierbar ja/nein, Bedingungen und **woran die Rezeption sie in ibelsa erkennt**.
