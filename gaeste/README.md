# Gästekommunikation

**Zweck:** Alle Systeme, die mit Gästen sprechen – Antworten, Bewertungen, Check-in, Telefon, Newsletter.

**Ist-Stand:**
| System | Aufgabe | Stand |
|---|---|---|
| COM25 | KI-E-Mail-Antworten | Trefferquote ~60 %, Ziel 80–85 %; Wissensbasis laufend aus `stammdaten/` schärfen |
| MARA | Bewertungsantworten | Brand Voice nachschärfen |
| Straiv | Online-Check-in, Gästekarte | läuft |
| Audavo | Telefon | läuft |
| Brevo | Newsletter | läuft |

**Tone of Voice:** Sie-Form, "Apartment" statt "Ferienwohnung", Gastgeber ist die Familie Huth, offiziell "Alpensonne Tegernsee (Hotel und Apartments)" – nie "Vital Hotel Alpensonne".

**Ansprechpartner:** Benno

**Abhängigkeiten:**
- nutzt: `stammdaten/` komplett (vor jedem Gästetext lesen), Feld `kommunikation` beachten
